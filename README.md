# MM2 Universal Protector Hub - Delta Executor Loadstring

## Quick Start

### Option 1: Direct Loadstring (Recommended)
Paste this into your Delta Executor:
```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/Blake680-arch/mm2-delta-hub/main/mm2_hub.lua'))()
```

### Option 2: Copy Full Script
Copy all contents of `mm2_hub.lua` and paste into Delta Executor

---

## Features

### Visual ESPs
- **Name Tags** - Shows player names and roles (Murderer/Sheriff/Innocent)
- **Aura Glow** - Color-coded highlights around players
- **Gun Tracker** - Highlights dropped sheriff gun

### Combat Tools
- **Shift Lock on Murderer** (Sheriff) - Hold Shift to lock onto murderer
- **Shift Lock on Victim** (Murderer) - Hold Shift to lock onto closest victim
- **Auto Pick Up Gun** (Sheriff) - Automatically picks up dropped gun

### UI
- 3 clean tabs with toggles
- All features toggleable in real-time
- No key system required

---

## Usage

1. Join MM2 game
2. Open Delta Executor
3. Paste loadstring into script box
4. Click Execute
5. Toggle features as needed
